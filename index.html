NOTE 01

为什么要把漫画做成「线路图」而不是榜单

榜单回答的是「现在什么最火」，但找作品的人更常问的是「有没有类似某某的那一类」。题材线路牺牲了热度信息的即时性，换来的是可预测的检索路径——这对导航站而言更实用。

线路组2026.09.28
NOTE 02

正版入口核验：三个工作日内会过期一次

授权平台的目录地址变动频率比预期高，尤其是季度番联动期。我们把核验周期定在 90 天，但实际观察中，部分平台 30 天内就会调整路径，这也是本期公告更新 312 条链接的原因。

资料组2026.09.25
NOTE 03

完结卷数标注比连载状态更有用

连载中的作品，读者真正想知道的是「要不要现在开始追」。标注完结卷数与单行本进度，能让新读者判断投入成本，也能帮老读者确认自己是否漏卷。

分类组2026.09.21
NOTE 04

港漫的分类困境：武侠之外还有什么

这次新增 N 线，我们把港漫拆成武侠、格斗、社会写实三类。但早期作品题材混杂，硬分类反而会误导，最终决定在作品资料页保留多重标签。

港漫组2026.09.16
NOTE 05

四格漫画的单行本与连载顺序是两回事

四格作品的单行本经常重排话数，读者按连载顺序找会找不到对应内容。目录中我们同时保留两种编号，并按单行本顺序作为默认展示。

资料组2026.09.12
NOTE 06

为什么目录页不放广告位

导航站的核心价值是检索效率。每多一个干扰元素，平均定位耗时就会增加。这一期我们把页面外的跳转也做了清理，目前从搜索到找到入口是三分钟。

常见问题FAQ / 关于 91漫画 的七个问题
Q.0191漫画（91manhua-zh.com.github.io）是漫画阅读网站吗？+
不是。91漫画是漫画目录与导航站点，只整理作品资料与正版阅读入口，不提供在线阅读功能，也不存储任何漫画文件。如果你要找的是某个具体的漫画网站，请在搜索框输入网站名称，我们会给出对应的导航信息。
Q.02为什么有的作品只有资料页，没有阅读入口？+
两种情况：一是尚未找到可确认的正版授权入口，二是作品涉及版权争议。前者会在三个工作日内由编辑部跟进核实，后者仅保留作者、出版社、卷数等资料，不提供任何阅读途径。完整说明见「服务台」。
Q.0314 条题材线路是怎么划分的？+
按读者群体（少年向、少女向、男性向、女性向）与题材类型双重划分，A 到 N 共 14 条线路，每条线路对应一个独立目录页。一部作品可以同时挂在多条线路下，以作品资料页的标签为准。
Q.04「到站时刻」表的更新时间是准确的吗？+
表中的话数与卷数来自出版社公开情报，编辑部每周一更新一次。「预计话数」是推算值，实际更新以官方发布为准。如发现标注有误，可通过「站内公告」中的纠错渠道反馈。
Q.05如何提交想找的作品？+
在「服务台」的求书入口提交作品名、作者与出版社（如有），编辑部三个工作日内回复。请提供尽可能完整的资料，这会影响核验效率。历史投稿记录可在个人中心查看。
Q.06成人向内容在哪里？+
M 线为成人向分类，目前仅提供资料页与分级说明，不提供阅读入口。本站坚持合规运营，涉及版权争议或违规内容一律不收录、不提供跳转。
Q.07这个目录可以转载或引用吗？+
可以。本站资料页的整理内容允许非商业用途转载，请保留原作者信息与本站出处（91manhua-zh.com.github.io）。商业用途请通过页脚「合作与转载」渠道联系编辑部。
